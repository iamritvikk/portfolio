# Ritvik Sharma — Portfolio

A responsive, dependency-free portfolio with an interactive WebGL sculpture, project filters, expandable project contributions, education records, contact actions, and mobile navigation.

## Open

Double-click `../Ritvik-Portfolio.html` for the fully self-contained version. It includes the supplied favicon, styles, JavaScript and 3D renderer. No install, build step, API key or internet connection is needed to display the portfolio. External résumé, project and credential links require internet access.

The editable version in this folder uses `index.html`, `styles.css`, `app.js`, `scene.js` and `favicon.ico`. Keep these files together.

## Edit

- Content, links and structure: `index.html`
- Colors, typography and responsive layouts: `styles.css`
- Menu, project filters, email copying and clock: `app.js`
- 3D geometry, lighting, orbit controls and fallbacks: `scene.js`

All 19 external portfolio links from the original have been preserved. Project visuals are custom illustrations; the court interface is explicitly labelled a workflow concept. The research credential is presented as a published patent application, not a granted patent.

## 3D controls

Drag to orbit. Focus the sculpture and use arrow keys to rotate, Shift + arrow keys for a larger step, and Home to reset. Use Pause/Play motion to toggle automatic rotation. System reduced-motion preferences are respected. Rendering pauses while offscreen and in hidden tabs; WebGL, Canvas2D and static fallbacks are provided.

## Verification

Checked in a Chromium-based browser at 320, 375, 390, 600, 620, 768, 820, 1024, 1440 and 1920 px widths with no horizontal page overflow. Mobile menu, anchor navigation, project filters, expandable details, education disclosure, and email copy feedback were checked. Browser reported no JavaScript errors. Script syntax and original URL preservation were also checked.

The external destinations were retained as supplied; their uptime and document permissions were not independently verified. The court platform keeps its original HTTP URL.
